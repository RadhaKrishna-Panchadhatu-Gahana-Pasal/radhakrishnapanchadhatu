CANVA:
1. Open Canva and create a design.
2. Choose Uploads > Upload files.
3. Upload the PNG/JPG for easy placement, or the SVG for a scalable Canva element.
4. Keep the logo on light ivory/cream backgrounds for best contrast.

IMPORTANT SVG NOTE:
The SVG files are Canva-compatible SVG containers with the high-resolution PNG artwork embedded.
They are not fully editable vector paths. Text and illustration are preserved as a single image.
For a fully path-based, recolourable vector master, the artwork would need manual vector tracing/redrawing.

The generated logo artwork is a clean recreation of the two references you selected.
